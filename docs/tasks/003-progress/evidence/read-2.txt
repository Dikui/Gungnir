## 它会做什么

`grilling` 提供共用的访谈方法，围绕计划、决策或想法持续提问，直到双方达成共同理解。

代理把议题整理成决策树：一项决策下面是依赖它的后续决策。前置条件已经确定、能够直接提问且无需猜答案的问题，组成当前的待问集合。

每轮问完待问集合中的所有问题。每题以 `❓`、编号和标题开头，推荐答案单独放在 `➡️` 后面，相邻问题用水平线分隔。你回答后，代理重新计算待问集合，再开始下一轮。

## 什么时候使用

不能直接调用，由 `/grill-me`、`/grill-with-docs` 等技能加载。没有其他技能要求加载时，代理应停止并提示你改用这两个入口。完整层级见[调用规则](../invocation.md)。

只需访谈时选择 `/grill-me`；需要同时维护领域文档时选择 `/grill-with-docs`。

## 这是对话，需要你做决定

查找事实由代理负责。问题依赖文件系统或工具中的信息时，它会派子代理查询，不会把能够自行查到的问题交给你。

查询未完成时，代理先问其他已具备前提的问题，只有依赖查询结果的问题需要等待。决策由你做，代理必须逐项提问并等你回答。

待问集合为空、每个分支都已处理且没有未说明的假设时，访谈可以结束。代理仍须等你确认双方达成共同理解后，再采取行动。

## 如何判断它有效

- 问题逐题编号，每题有单独的推荐答案。
- 本轮问题不依赖本轮尚未确定的答案。
- 回答会改变后续问题，而不是沿用预先写好的问卷。
- 查询事实不阻塞其他已具备前提的问题，代理也不替你做决策。
- 结束条件得到满足，行动前取得你的共同理解确认。

## 常见问题

**为什么不一次只问一个问题？**

当前方法按轮次问完所有已具备前提的问题。依赖本轮答案的问题留到下一轮，避免在前提未定时要求你猜测。

**推荐答案就是最终决定吗？**

不是。推荐供你比较和取舍，代理必须等你回答。你可以按编号选择、反对或补充条件。

**同一轮里出现了相互依赖的问题怎么办？**

指出依赖关系，让代理把依赖未定答案的问题留到后续轮次。它需要按你的回答重新计算待问集合。

## 它在工作流中的位置

它是基础技能，集中维护访谈方式。除两个访谈入口外，`/triage`、`/wayfinder` 和 `/improve-codebase-architecture` 也会按各自步骤加载它。

它负责把决策问清楚；领域术语和重要架构决策的记录由 `/domain-modeling` 提供。
## 它会做什么

`to-tickets` 将计划、需求文档或当前讨论拆成可独立验证的任务，注明前置依赖，再发布到项目任务跟踪器。

每项任务是一条贯通数据结构、接口、界面和测试等各层的窄而完整的路径，完成后可以独立演示或验证，规模适合一次新会话。代理会先查找并完成能让后续实现更容易的预先重构。

## 什么时候使用

当方案已明确，但工作需要分成多个会话实施时，使用 `/to-tickets`。可以提供需求文档路径或任务编号，也可以直接使用当前讨论；提供已有任务时，代理会完整读取正文和评论。

由你输入 `/to-tickets` 调用，代理不会自行调用。

项目必须已有任务跟踪器和分流标签配置。缺失时，代理会提示你先显式运行 `/setup-dikui-skills`。

## 这是对话，需要你做决定

发布前，代理用编号列表展示任务标题、前置依赖和交付的完整行为。你需要确认粒度、依赖是否必要且正确，以及哪些任务应合并或继续拆分。

代理根据回答调整，直到你批准，再按前置任务优先的顺序发布。它不会关闭或修改父任务。

## 如何判断它有效

- 每项任务都能回答“完成后可以演示什么行为”，而不是只完成某个技术层。
- 前置依赖明确，没有依赖的任务可以立即开始。
- 每项任务有验收条件，使用项目领域词汇，并遵守相关 ADR（架构决策记录）。
- 任务单能支持新会话接手，避免易过时的具体文件路径和代码；必要的原型决策片段注明来源。
- 发布结果与批准的拆分一致，本地任务各占一个文件，远程任务正确记录依赖。

## 常见问题

**任务太碎，或按技术层拆分怎么办？**

在确认步骤要求合并或重拆。每项应交付完整行为，不能把数据结构、接口和界面分别当成独立交付。整个改动能在一次会话完成时，可以直接用 `/implement`。

**大范围机械重构也必须逐项独立通过检查吗？**

列重命名、共享类型替换等改动按“扩展 → 迁移 → 收缩”拆分：保留旧形式并增加新形式，分批迁移调用方，最后删除旧形式。迁移任务依赖扩展任务，收尾任务依赖全部迁移任务。

若迁移批次仍无法独立通过检查，各批共享集成分支，并作为最后“集成并验证”任务的前置条件，只在最后要求整体通过。

**任务保存在哪里，依赖怎样表达？**

- 本地每项保存到 `.scratch/<feature-slug>/issues/<NN>-<slug>.md`，从 `01` 开始编号，`Blocked by` 写明前置任务编号和标题。
- 远程每项创建一个任务；支持时用原生依赖或子任务关系，否则在 `Blocked by` 中引用前置任务，默认添加 `ready-for-agent` 标签。

**发布后会自动分派实施吗？**

任务发布后，由你选择实施方式，并先处理前置任务均已完成的任务。该技能不启动实施代理；它生成的任务也不需要再交给 `/triage` 分流。

## 它在工作流中的位置

多次会话的工作通常先由 `/to-spec` 收拢需求，再在同一上下文用 `/to-tickets` 拆分。之后每项任务用新会话调用 `/implement`，或用 `/implement-spec` 按依赖图并行实施整份需求。
## 它会做什么

`wayfinder` 把一次会话无法规划清楚的大任务整理成任务跟踪工具中的决策地图，逐项解决实施前的待定问题，直到路径明确。

地图是带 `wayfinder:map` 标签的问题单，决策任务单是它的子问题单。地图只保存摘要和链接，详细答案写在对应任务单中；每次会话先读地图，再按需读取相关任务。

地图用 `Destination` 明确目标，用 `Notes` 记录持续适用的约定，用 `Decisions so far` 索引已完成决策。暂时说不清的问题放入 `Not yet specified`，范围外事项放入 `Out of scope`。

## 什么时候使用

当任务需要多次会话，且通往目标的路线仍不清楚时，由你输入 `/wayfinder` 调用，代理不会自行调用。

你可以提供一个想法，也可以提供已有地图的地址、编号或指定任务单。若初步访谈发现路径已清楚、一次会话就能完成，代理不建立地图，而是停止并询问你如何继续。

## 这是对话，需要你做决定

代理先通过 `/grilling` 和 `/domain-modeling` 与你明确目标，只为当前能说清的问题建立任务单。任务分为四类：

- `grilling`：通过实时对话形成决策，是默认类型；代理不能替你回答。
- `prototype`：用粗略产物讨论外观或行为，需要你参与；界面或逻辑代码可用 `/prototype`。
- `research`：获取当前工作目录以外的事实，交给 `/research` 子代理独立处理。
- `task`：执行解除决策阻塞所需的操作；代理不能独立完成时，给你准确的操作清单。

建图占一次会话，不再手动解决其他任务；新建的 `research` 任务会并行启动子代理，结果保存在临时使用的 `research/<name>` 分支，并从任务单链接到结果。继续地图时，每次会话最多解决一张任务单，调研任务除外。

开始工作前先分配任务给推进地图的开发者，其他会话跳过已分配任务。属于当前地图、未关闭、未分配且所有前置任务均已关闭的任务，才可领取。

## 如何判断它有效

- 目标先于任务确定，每张任务单只描述一个能在一次会话中处理的问题。
- 能说清的问题成为任务单，暂时说不清的问题保留在 `Not yet specified`。
- 任务完成后有完成评论，任务已关闭，地图只新增摘要和链接。
- 新问题转成任务后从 `Not yet specified` 移除；失效任务被更新或删除。
- 范围外任务被关闭并记入 `Out of scope`，不算已完成决策。

## 常见问题

**它会直接实现目标吗？**

默认只做规划，直到实施前无待定事项且无剩余任务，再交接执行。需要包含实际交付时，必须在地图的 `Notes` 中明确说明。默认规划流程中的 `task` 可以执行实际操作，但用途是解除决策阻塞。

**必须使用某个任务跟踪工具吗？**

它读取配置中的 `Wayfinding operations`，使用其中的父子关系、依赖和待办查询方式。尚无配置时提示你显式调用 `/setup-dikui-skills`；没有任务跟踪工具时默认使用 `local-markdown`。依赖优先用原生关系表示，不支持时才写入正文。

**它与 `/grill-with-docs` 有什么区别？**

`/grill-with-docs` 适合一次会话中的方案访谈；本技能用地图承接多次会话中的待定问题。决策任务单解决问题，不等同于实现任务单。

## 它在工作流中的位置

地图清楚后，由你调用 `/to-spec` 收拢相互关联的决策，再用 `/to-tickets` 拆出实现任务并进入 `/implement`。只有最终发现任务很小时，才直接进入 `/implement`。
// Check the repo invariants from AGENTS.md and docs/invocation.md:
// invocation tiers, plugin manifest, README indexes and version sync.
import { readFileSync } from 'node:fs'
import { join } from 'node:path'

import { BUCKETS, ROOT, listSkills } from './skills.mjs'

const DESCRIPTION_GATE = '不要根据对话内容自行加载'
const BODY_GUARD = '加载条件：'

let failed = false
function fail(file, msg) {
  failed = true
  console.error(`✗ ${file}: ${msg}`)
}
const read = (rel) => readFileSync(join(ROOT, rel), 'utf8')

/**
 * Collect `- **[name](link)**` index entries and the invocation group heading they sit under.
 *
 * @param {string} text - README content.
 * @returns {Map<string, { link: string, group: string | null }>}
 */
function indexEntries(text) {
  const entries = new Map()
  let group = null
  for (const line of text.split('\n')) {
    const heading = line.match(/^(?:#+\s*|\*\*)(User-invoked|Skill-invoked)(?:\*\*)?\s*$/)
    if (heading) {
      group = heading[1]
      continue
    }
    if (line.startsWith('#')) group = null
    const item = line.match(/^- \*\*\[([^\]]+)\]\(([^)]+)\)\*\*/)
    if (item) entries.set(item[1], { link: item[2], group })
  }
  return entries
}

const skills = listSkills()
const all = skills

// Invocation tiers: frontmatter and agents/openai.yaml must agree.
const invocationDoc = read('docs/invocation.md')
for (const s of all) {
  const file = `${s.path}/SKILL.md`
  if (!s.meta) {
    fail(file, 'missing or malformed frontmatter')
    continue
  }
  const userOnly = s.meta['disable-model-invocation'] === 'true'
  s.group = userOnly ? 'User-invoked' : 'Skill-invoked'
  const implicit = s.openaiYaml?.match(/allow_implicit_invocation:\s*(true|false)/)?.[1]
  if (!implicit) fail(`${s.path}/agents/openai.yaml`, 'missing policy.allow_implicit_invocation')
  else if (implicit !== String(!userOnly)) {
    fail(`${s.path}/agents/openai.yaml`, `allow_implicit_invocation should be ${!userOnly} for a ${s.group} skill`)
  }
  const listedInDoc = invocationDoc.includes(`| \`${s.name}\` |`)
  if (userOnly) {
    if (s.meta['user-invocable'] === 'false') fail(file, 'user-invocable: false needs model invocation enabled')
    if (listedInDoc) fail('docs/invocation.md', `${s.name} is listed as Skill-invoked but sets disable-model-invocation`)
    continue
  }
  if (!s.meta.description?.includes(DESCRIPTION_GATE)) fail(file, `Skill-invoked description must contain "${DESCRIPTION_GATE}"`)
  if (!s.body.trimStart().startsWith(BODY_GUARD)) fail(file, `Skill-invoked body must start with "${BODY_GUARD}"`)
  if (!listedInDoc) fail('docs/invocation.md', `Skill-invoked table is missing ${s.name}`)
}

// Public entry skills must be discoverable through ask-dikui.
const askDikuiFile = 'skills/engineering/ask-dikui/SKILL.md'
const askDikui = read(askDikuiFile)
for (const s of skills.filter((s) => s.public)) {
  if (s.name === 'ask-dikui' || s.meta?.['disable-model-invocation'] !== 'true' || s.meta['user-invocable'] === 'false') continue
  const name = s.name.replace(/[.*+?^${}()|[\]\\]/g, '\\$&')
  if (!new RegExp(`/${name}(?![A-Za-z0-9-])`).test(askDikui)) {
    fail(askDikuiFile, `${s.name}: 在 ask-dikui 中登记该技能`)
  }
}

// Plugin manifest lists exactly the public buckets.
const plugin = JSON.parse(read('.claude-plugin/plugin.json'))
const expected = skills.filter((s) => s.public).map((s) => `./${s.path}`).sort()
const actual = [...plugin.skills].sort()
for (const path of expected) if (!actual.includes(path)) fail('.claude-plugin/plugin.json', `missing ${path}`)
for (const path of actual) if (!expected.includes(path)) fail('.claude-plugin/plugin.json', `unexpected ${path}`)

// Top README indexes every public skill under its invocation group, and nothing else.
const readme = read('README.md')
const top = indexEntries(readme)
for (const s of skills.filter((s) => s.public)) {
  const entry = top.get(s.name)
  if (!entry) fail('README.md', `missing index entry for ${s.name}`)
  else if (entry.link !== `./${s.path}/SKILL.md`) fail('README.md', `${s.name} should link to ./${s.path}/SKILL.md`)
  else if (s.group && entry.group !== s.group) fail('README.md', `${s.name} should be listed under ${s.group}`)
}
for (const m of readme.matchAll(/\(\.\/skills\/(in-progress|deprecated)\/([^/)]+)/g)) {
  fail('README.md', `must not reference ${m[1]} skill ${m[2]}`)
}

// Each bucket README indexes its own skills; public buckets also group them.
for (const bucket of BUCKETS) {
  const file = `skills/${bucket}/README.md`
  const entries = indexEntries(read(file))
  for (const s of skills.filter((s) => s.bucket === bucket)) {
    const entry = entries.get(s.name)
    if (!entry) fail(file, `missing index entry for ${s.name}`)
    else if (entry.link !== `./${s.name}/SKILL.md`) fail(file, `${s.name} should link to ./${s.name}/SKILL.md`)
    else if (s.public && s.group && entry.group !== s.group) fail(file, `${s.name} should be listed under ${s.group}`)
  }
  for (const name of entries.keys()) {
    if (!skills.some((s) => s.bucket === bucket && s.name === name)) fail(file, `lists unknown skill ${name}`)
  }
}

// The dsh package ships the same version as the Claude plugin.
const dsh = JSON.parse(read('dsh-plugin/package.json'))
if (dsh.version !== plugin.version) fail('dsh-plugin/package.json', `version ${dsh.version} != plugin ${plugin.version}`)

if (!failed) console.log(`ok: ${all.length} skills checked`)
process.exit(failed ? 1 : 0)
import fs from "node:fs";
import { execSync } from "node:child_process";

const files = execSync("git ls-files '*.md'", { encoding: "utf8" })
  .trim()
  .split("\n")
  .filter((file) => file && fs.existsSync(file))
  .filter((file) => file !== "LICENSE.zh-CN.md");

const allowed = [
  "TDD",
  "PRD",
  "ADR",
  "DDD",
  "API",
  "CLI",
  "CI",
  "CD",
  "GitHub",
  "Claude",
  "Codex",
  "Obsidian",
  "Husky",
  "Prettier",
  "lint-staged",
  "red-green-refactor",
  "mock",
  "refactor",
  "README",
  "LICENSE",
  "SKILL",
  "MIT",
];

function stripCodeFences(text) {
  return text.replace(/```[\s\S]*?```/g, "");
}

let suspicious = false;
for (const file of files) {
  const raw = fs.readFileSync(file, "utf8");
  const text = stripCodeFences(raw);
  const lines = text.split("\n");
  lines.forEach((line, index) => {
    const trimmed = line.trim();
    if (!trimmed) return;
    if (/^---$/.test(trimmed)) return;
    if (/^(name|description):/.test(trimmed)) return;
    if (/https?:\/\//.test(trimmed)) return;
    let scrubbed = trimmed;
    for (const term of allowed) {
      scrubbed = scrubbed.replaceAll(term, "");
    }
    const englishWords = scrubbed.match(/[A-Za-z]{4,}/g) || [];
    if (englishWords.length >= 8) {
      suspicious = true;
      console.log(`${file}:${index + 1}: ${trimmed}`);
    }
  });
}

if (suspicious) {
  console.error("\nPotential English-heavy lines remain. Review manually.");
  process.exit(1);
}
