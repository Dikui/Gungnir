# 分流标签

技能使用五个标准分流状态。本文件把它们对应到本仓库 issue tracker 中实际使用的标签字符串。

| 标准状态 | 本仓库使用的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，可交给代理独立处理 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不处理 |

技能提到某个标准状态时，使用本表中对应的标签字符串。

按实际使用的标签修改第二列。
