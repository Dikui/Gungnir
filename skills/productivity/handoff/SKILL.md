---
name: handoff
description: 将当前对话整理成交接文档，供其他代理继续工作。
argument-hint: "下一个会话将用于什么？"
disable-model-invocation: true
---

编写交接文档，总结当前对话，让新的代理可以接手。保存到操作系统的临时目录，不要放在当前工作区。

在文档中加入 `suggested skills` 小节，列出建议下一个代理使用的技能。此小节只提供建议，实际调用仍需用户明确指定。

不要重复其他资料（需求文档、计划、ADR、issue、提交、差异）中已有的内容；用路径或 URL 引用它们。

删除敏感信息，例如 API 密钥、密码 或个人身份信息。

如果用户提供了参数，把它们作为下次会话的关注点，并据此调整文档。
